Xmx (максимум)
Xms (стартовый)

Число + M или G (например 2G, 512M). Xms == Xmx часто советуют для Minecraft — так JVM не тратит время на увеличение кучи во время прогрева/генерации мира. Меняется только для нового старта — на уже запущенный процесс не действует, нужен рестарт.

Автоустановщик сборки для TLauncher

{% if pack_ready %} готов {% else %} не готов {% endif %}

Игрок скачивает один .bat-файл и запускает его: тот сам находит папку TLauncher, ставит загрузчик и нужную версию Minecraft, создаёт в versions папку с названием сборки и кладёт туда моды, конфиги, шейдеры и текстуры. Повторный запуск того же файла обновляет сборку — докачивается только изменившееся. Чтобы установщик заработал, нужны название и установщик загрузчика; моды и overrides — по желанию.

1. Название сборки
Так версия будет называться в списке TLauncher. Смена названия создаст у игроков новую версию рядом со старой.
