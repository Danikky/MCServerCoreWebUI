Xmx (максимум)
Xms (стартовый)

Число + M или G (например 2G, 512M). Xms == Xmx часто советуют для Minecraft — так JVM не тратит время на увеличение кучи во время прогрева/генерации мира. Меняется только для нового старта — на уже запущенный процесс не действует, нужен рестарт.
